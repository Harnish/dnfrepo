# Container Registry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dnfrepo embeds the Distribution registry and serves `/v2/` with per-repo Listed/Access settings, push tokens, an admin UI, GC, and a public read-only browse page.

**Architecture:** `internal/registry` wraps `handlers.NewApp` (filesystem driver). A registered `auth.AccessController` delegates every request to a pure `Policy` (modes public/ips/users, push tokens, anonymous rules) backed by new store tables. dnfrepo serves `/v2/_catalog` itself (filter, then paginate) and gates writes during GC. Admin and public JSON APIs and React pages sit on top.

**Tech Stack:** Go 1.26, `github.com/distribution/distribution/v3@v3.1.2` (filesystem driver only), pgx, React/TS (vitest).

**Spec:** `docs/superpowers/specs/2026-11-15-registry-design.md`

## Global Constraints

- Registry disabled unless `REGISTRY_DIR` is set; rpm/deb behaviour unchanged when unset.
- Import only `registry/storage/driver/filesystem`; delete enabled in registry config.
- Access per repo is exactly one of `public` / `ips` / `users` (`store.ModePublic|ModeIPs|ModeUsers`); default `public`, Listed default `false`.
- Push never anonymous; push tokens (global) may create/push/pull; `DELETE` over HTTP is refused for everyone (tag delete and GC are admin-UI only).
- Anonymous request to a name that is not anonymously readable OR does not exist: 401 with `WWW-Authenticate: Basic realm="dnfrepo registry"`. Authenticated-but-forbidden: 401 as well, never 404.
- Anonymous catalog = repos anonymously readable AND Listed; authenticated catalog = every repo the caller may pull. Public page uses the anonymous rule.
- Tokens: hashed (`hashTok` style, sha256 hex), shown once, revocable; never logged. Basic username `:` forbidden.
- Auth failures use `access.Throttle` (`Attempt` before check, `Reset` on success), IP via `access.ClientIP(r, trusted)`.
- No body-size cap, no write timeout on `/v2/` (server sets only `ReadHeaderTimeout`).
- GC: gate rejects writes/deletes with 503 at once, waits up to 60 s for in-flight writes, else aborts and reports; pulls continue.
- New migration `internal/store/migrations/010_registry.sql`; never edit applied ones.
- TDD; commits are conventional and **only after asking the user** (project + global CLAUDE.md). Tests: `DNFREPO_TEST_DSN=postgres://postgres:pw@localhost:5433/postgres go test ./...` with the `dnfrepo-pg` podman container from CLAUDE.md (stop it when done), plus `go vet ./...`; web: `cd web && npm test && npx tsc --noEmit && npm run build`.

## Review Focus

1. Existence leak: anon pull of a `users`-mode repo, an unknown name, and an `ips`-denied name all return the same 401 (Task 2).
2. Catalog paging: `n`/`last` over a filtered list must not return short pages while more remain (Task 4).
3. Anonymous or revoked-token push and HTTP `DELETE` with a valid push token are refused (Tasks 2, 3).
4. Upload in flight when GC starts: GC waits, then aborts after the deadline without sweeping; pulls keep working (Task 6).
5. Nested and mixed names (`a/b/c`, names containing `.` `_` `-`) work in settings, grants, catalog and admin API (Tasks 1, 4, 7).
6. `/v2/` mount does not shadow `/r/`, `/api/`, `/healthz` or the SPA (Task 8).

### Task 2: Policy — who may do what

**Files:**
- Create: `internal/registry/policy.go`, `internal/registry/policy_test.go`

**Interfaces:**
- Consumes: Task 1 store methods; `access.ClientIP`, `access.NewThrottle`.
- Produces:
  - `type PolicyStore interface { RegistryRepoByName; EnsureRegistryRepo; RegistryIPs; CheckRegistryUser; CheckPushToken }` (the subset used).
  - `type Policy struct { Store PolicyStore; Trusted []netip.Prefix; Throttle *access.Throttle; Exists func(ctx context.Context, name string) bool }`
  - `type Caller struct { Anonymous bool; Push bool; User string }`
  - `type Verdict int` with `Allow`, `Challenge` (401), `Throttled` (429), `Error` (500).
  - `func (p *Policy) Identify(r *http.Request) (Caller, Verdict)` — no Basic header → anonymous/`Allow`; push token creds → `Push=true`; otherwise `User` set only if the name resolves later (credentials validated per repo in `CanPull`); wrong creds or throttle → `Challenge`/`Throttled`. Throttle `Attempt` runs before any credential check and `Reset` on success.
  - `func (p *Policy) CanPull(r *http.Request, c Caller, repo string) (bool, error)` — push token: true; public: true; ips: client IP in prefixes; users: `CheckRegistryUser` with the Basic creds.
  - `func (p *Policy) Authorize(r *http.Request, accesses []Access) Verdict` where `Access{Repo, Action string}` (`pull`, `push`, `delete`, or `catalog`): `delete` → `Challenge`-style refusal 401 (never allowed); `push` needs `Push`, else `Challenge`; `pull` needs `CanPull`, else `Challenge` (identical for unknown names); a granted `push` calls `EnsureRegistryRepo`; `catalog` allowed for everyone (filtering happens in Task 4).

- [ ] **Step 1: Tests** (use a small in-memory `fakeStore`, one test per rule): `TestAnonPullPublicAllowed`, `TestAnonPullExistingImageWithoutRow` (a repo that exists in storage but has no settings row is public: allowed — this is every image at cutover), `TestAnonPullIdenticalDenials` (anonymous pull of a `users`-mode repo, an `ips`-denied repo, and a name that exists nowhere all return the same `Challenge`), `TestUsersModeNeedsGrant`, `TestIPsModeUsesClientIP` (with and without trusted XFF), `TestPushNeedsPushToken` (anonymous, user-token, revoked token → `Challenge`), `TestPushTokenCreatesRow` (`EnsureRegistryRepo` called), `TestDeleteAlwaysRefused` (even push token), `TestThrottleCountsBeforeCheck` (11 bad attempts from one IP → `Throttled`; node pulling anonymously from same IP is not counted), `TestBasicUsernameRulesAreExact` (`:` in user rejected).
- [ ] **Step 2: Run** `go test ./internal/registry -v` — Expected: FAIL, undefined.
- [ ] **Step 3: Implement** the types above in `policy.go`. Decision: a name with no settings row uses defaults (public) **only if it exists in storage**, via `Policy.Exists func(ctx context.Context, name string) bool` (set by `registry.New`; tests inject a fake); a name that exists nowhere is `Challenge` for anonymous callers, so unknown names 401 like non-public ones.
